# ReaderAgent 精读训练 · 产品规格 v1.0

> 归属：EnglishCoach 品牌矩阵「精读」专项，与 ReadingCoach（阅督=做题）互补。
> 目标用户：高中学生（王梓攸=高一，2029 高考）+ 家长监督。
> 核心定位：**AI 带读真实外刊，训练精读能力 + 泛读速度，读后以概要写作/读后续写输出，AI 评分 + 回炉。**

---

## 一、两条线（分开）

| | 精读线 | 泛读线 |
|---|---|---|
| 频率 | 每周 2–3 篇 | 每天 1 篇 |
| 单篇时长 | 约 30 分钟 | 约 10–15 分钟 |
| 语料 | 真实外刊单篇（600–1000 词） | 短文章（150–300 词） |
| 目标 | 读懂每一句（词汇/长难句/背景/观点） | 抓大意、提速、扩大阅读量 |
| 输出 | 概要写作 / 读后续写 + 评分 | 大意检测 + 快速反馈 |

---

## 二、精读线 · 核心闭环

```
选一篇真实外刊（按难度分级）
  ↓
① AI 带读（逐段）—— 每段提取四类：
   生词 Word：音标 + 释义 + 例句
   长难句 Sentence：主谓宾 / 从句拆解
   背景 Context：文化 / 时事 / 背景知识
   观点 Idea：作者论点 + 论据 + 论证逻辑
  ↓
② 精读理解检测（开放式，检测真读懂）
   "这段作者的核心观点是什么？""某句话的言外之意？"
  ↓
③ 读后输出（主任务）
   概要写作（主）：60–100 词概括全文
   读后续写（兼顾）：记叙文类续写 1–2 段
  ↓
④ AI 评分 + 反馈（DeepSeek）
   概要：要点覆盖 / 语言准确 / 连贯性
   续写：情节合理 / 衔接 / 语言
  ↓
⑤ 回炉（复用 DailyCoach 1/3/7 天机制）
   读不懂的段落 / 写错的点
```

---

## 三、泛读线 · 核心闭环

```
选一篇短文章（难度略低于精读）
  ↓
快速读（可选限时，培养速度）
  ↓
大意检测：主旨 + 2–3 个关键信息点（开放式或轻量判断）
  ↓
快速反馈：大意识别对不对
  ↓
打卡（轻量，不做写作）
```

**泛读不做**：逐段带读、生词精讲、写作输出（那是精读的活）。

---

## 四、语料来源与拆分

**由我（AI）负责拆分**：现有 ReaderAgent 从 GitHub 拉整本英语杂志 PDF（经济学人/纽约客等），需拆成单篇。

拆分方案：
1. PDF 解析（现有 PDF 解析能力）→ 提取文本 + 结构
2. 按标题 / 分页 / 空行 / 栏目边界，识别单篇边界
3. LLM 辅助：确认单篇标题 + 正文范围 + 词数 + 难度评级
4. 入库为「单篇文章」：标题、正文、来源、词数、难度档

---

## 五、难度分级（衔接 DailyCoach 5 档，针对真实外刊重新定义）

| 档位 | 目标 | 词数（精读） | 特征 |
|---|---|---|---|
| L1 | 初中拔高 | 300–500 | 短句、日常话题、少量生词 |
| L2 | 会考基础 | 400–600 | 常见高中词汇、少量复合句 |
| L3 | 高考过渡 | 500–800 | 长难句、科技/文化话题 |
| L4 | 高考标准 | 700–1000 | 抽象话题、词汇密度高 |
| L5 | 高考压轴 | 900–1200 | 长难句、复杂论证、时事评论 |

## 六、评分与回炉

- 评分：复用 DeepSeek（同 SpeakingCoach/ReadingCoach 后端 key）
- 回炉：复用 DailyCoach 错题回炉（1/3/7 天重练，练对 3 次出队）
  - 精读：读不懂的段落、概要写作漏掉的要点
  - 泛读：大意识别错误的文章

- 新增：外刊语料库、单篇拆分、AI 带读（生词/长难句/背景/观点）、概要写作/读后续写题型

## 八、明确不做

- ❌ 四选一刷题（ReadingCoach 的活）
- ❌ 全文翻译工具（ChatGPT 干的）
- ❌ 成人论文「认同/存疑」导读（已确认臆想需求）
- ❌ 初期不做七选五、完形、任务型阅读（ReadingCoach P4 扩展范围）
