一句话结论

这篇论文把关系数据学习的三大环节——特征工程、建模、检索——交给一个 LLM Agent 自动完成，首次在 RelBench 基准上全面超越人工特征工程。

贡献 1 Agentic 特征工程：让 LLM 在 SQL 特征空间里自主搜索 ›
传统关系学习最耗人力的是特征工程——要理解多张表的主外键关系，手工构造聚合、时序、图结构特征。RelAgent 把这一步变成 LLM agent 的搜索问题：agent 在「SQL 查询定义的特征空间」里迭代生成候选特征、在验证集上评估、保留有效特征继续深挖，形成一个自动化的特征发现闭环。

贡献 2 自省式检索：agent 从自己的失败特征里学习 ›
纯「生成-评估」的 agent 容易在特征空间里打转。RelAgent 引入自省（self-reflection）：把 agent 之前生成过、但表现差的特征存进记忆库，生成新特征前先检索这些「失败案例」，让 agent 主动避开低效路径。这让搜索更聚焦，也是它效率超越纯 LLM 的关键。

贡献 3 RelBenchV1 全面 SOTA：20 个数据集 15 个登顶 ›
在 RelBench 的 20 个真实关系数据集上，RelAgent 在 15 个上取得第一，平均相对提升约 10%，且无需任何人工特征。对比对象包括手工特征工程的强 baseline（GNN、表格模型）以及零样本 LLM 方法，说明 agent 自动发现的特征质量已经稳定超过人。

贡献 4 端到端自动化：原始表进，最终预测出 ›
从多张原始关系表，到最终的任务预测结果，全程无需人工介入。这不仅是特征工程的自动化，而是把「理解 schema → 构造特征 → 建模 → 调优」整条数据科学流水线压缩进一个 agent。对工业界而言，这意味着关系学习从「专家手艺」变成「可规模化的自动流程」。
